# Local run

```bash
cargo run -p visado -- deploy/local/visado.toml
curl localhost:8080/.well-known/jwks.json
```

visado expects an AuthZEN PDP at `127.0.0.1:8181`. The keys in `keys/` are fixed demo keys generated by `cargo run -p visado-testkit --example demo_keys`. They are public; do not use them anywhere else.
