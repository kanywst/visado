# Adopters

visado is pre-alpha, so there are no production adopters. Evaluations, test setups and interop work count: if you run visado for any of these, add yourself.

## Adding an entry

Open a pull request that adds one row to the table, in alphabetical order. Sign off the commit (`git commit -s`, see [CONTRIBUTING.md](CONTRIBUTING.md)).

- **Adopter**: the organization or project, linked to its site or repository. Individuals may list themselves by GitHub handle.
- **Stage**: `evaluation`, `testing`, `interop` or `production`.
- **Since**: year and month, `YYYY-MM`.
- **Use**: one line on what visado does for you, such as the proxy it runs behind and the credentials or chains it verifies.
- **Contact**: a GitHub handle that can answer questions about the entry.

A maintainer checks the entry with the contact before merging. Ask to be removed at any time by issue or pull request.
