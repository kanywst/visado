# Conformance vectors

Language-neutral test vectors. Each suite is one JSON file:

| Field | Meaning |
| --- | --- |
| `format` | `visado-conformance/v1` |
| `suite`, `spec` | What is tested and against which draft revision |
| `validation` | Verifier settings shared by every case (`trust_domain`, `now`, `leeway`, `max_lifetime`) |
| `keys` | Trusted keys as `{kid, jwk}` |
| `valid` | Tokens that must verify |
| `negative` | Tokens that must be rejected, with the expected error code in `expect` |

An implementation passes when every `valid` token verifies and every `negative` token is rejected for the reason in `expect`. Rejecting for a different reason is a failure.

## Regenerating

The vectors are generated by `crates/txn-token/tests/conformance.rs`, which also fails when the committed file is stale:

```bash
VISADO_REGENERATE=1 cargo test --workspace
```
